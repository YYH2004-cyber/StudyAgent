# TCP 与 UDP 的区别

> 分类：计算机网络 | 日期：2026-10-12 | 标签：网络, 基础

## 核心对比

| 维度 | TCP | UDP |
|------|-----|-----|
| 连接 | 面向连接 | 无连接 |
| 可靠性 | 可靠（确认、重传、按序） | 尽力交付，不保证 |
| 速度 / 头部 | 较慢，头部 ≥20 字节 | 快，头部仅 8 字节 |
| 传输模式 | 字节流 | 数据报（有边界） |
| 拥塞控制 | 有 | 无 |
| 一对多 | 不支持（需自建） | 支持广播/多播 |

## 三次握手（建立 TCP 连接）

1. 客户端 → 服务端：`SYN, seq=x`
2. 服务端 → 客户端：`SYN+ACK, seq=y, ack=x+1`
3. 客户端 → 服务端：`ACK, ack=y+1`

为什么是三次：通信双方都要确认"我发的对方收到了、对方发的我也收到了"；两次无法让服务端确认自己的发送能力，也无法抵御历史失效的连接请求。

## 适用场景

- TCP：HTTP/HTTPS、文件传输、SSH、邮件
- UDP：DNS、视频直播、在线游戏、DHCP
