# 正则表达式常用模式

> 分类：编程 | 日期：2026-10-12 | 标签：regex, 速查

## 常用元字符

| 符号 | 含义 | 符号 | 含义 |
|------|------|------|------|
| `\d` / `\D` | 数字 / 非数字 | `^` `$` | 行首 / 行尾 |
| `\w` / `\W` | 字母数字下划线 / 取反 | `[abc]` | 字符集合 |
| `\s` / `\S` | 空白 / 非空白 | `|` | 或 |
| `.` | 任意字符（默认除换行） | `(...)` | 分组捕获 |
| `*` | 0 次或多次 | `(?:...)` | 非捕获分组 |
| `+` | 1 次或多次 | `(?=...)` | 正向先行断言 |
| `?` | 0 或 1 次 | `\b` | 单词边界 |
| `{n,m}` | n 到 m 次 | 贪婪量词加 `?` | 懒惰匹配 |

## 实用正则

```regex
# 邮箱（宽松版，日常够用；严格校验请发验证邮件）
^[\w.+-]+@[\w-]+\.[\w.]+$

# 日期 yyyy-MM-dd
^\d{4}-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])$

# 中国大陆手机号
^1[3-9]\d{9}$

# 提取 URL 中的域名（捕获组 1）
https?://([^/]+)
```

## 注意

- `.` 默认不匹配换行，多行文本用 `re.S`（Python）或 `s` 标志。
- 手机号 / 邮箱的正则"宽松够用"即可，业务规则一直在变，写太严反而误伤。
- 能用 `startswith` / `in` / `split` 就别上正则；正则复杂到看不懂时，考虑用解析库。
