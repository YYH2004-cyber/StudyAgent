# HTTP 状态码详解

> 分类：计算机网络 | 日期：2026-10-12 | 标签：http, web, 基础

## 五大类

| 类别 | 含义 | 典型状态码 |
|------|------|------------|
| 1xx | 信息，协议中间状态 | 101 Switching Protocols（WebSocket 升级） |
| 2xx | 成功 | 200 / 201 / 204 |
| 3xx | 重定向 | 301 / 302 / 304 |
| 4xx | 客户端错误 | 400 / 401 / 403 / 404 / 429 |
| 5xx | 服务端错误 | 500 / 502 / 503 / 504 |

## 高频状态码速记

- **200** 成功；**201** 已创建（POST 建资源）；**204** 成功但无响应体（DELETE 常用）。
- **301** 永久重定向（SEO 权重转移）；**302** 临时重定向；**304** 协商缓存命中，浏览器用本地缓存。
- **401** 未认证（没登录）；**403** 已认证但没权限；**404** 资源不存在；**429** 请求过于频繁（被限流）。
- **500** 服务器内部错误；**502** 网关收到坏响应（后端进程挂了）；**503** 服务不可用；**504** 网关等待上游超时。

## 排查思路

- 4xx：问题在客户端——抓包看 URL、参数、认证头、Content-Type。
- 5xx：问题在服务端——看应用日志和依赖（DB、下游服务）；502/504 多半是网关到上游的链路问题。
- 304 不是错误，是缓存协商成功的正常表现。
