# 大 O 时间复杂度速查

> 分类：算法 | 日期：2026-10-12 | 标签：算法, 基础

## 常见复杂度等级

从快到慢：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)

| 复杂度 | 名称 | n=100 时的量级感受 |
|--------|------|--------------------|
| O(1) | 常数 | 1 步：哈希取值、数组按下标访问 |
| O(log n) | 对数 | ~7 步：二分查找 |
| O(n) | 线性 | 100 步：一次遍历 |
| O(n log n) | 线性对数 | ~664 步：归并/堆排序、快排平均 |
| O(n²) | 平方 | 10000 步：双重循环 |
| O(2ⁿ) | 指数 | 天文数字：子集枚举、朴素递归 |
| O(n!) | 阶乘 | 全排列 |

## 典型代码示例

```python
# O(1)：与输入规模无关
def first(nums):
    return nums[0]

# O(log n)：每轮问题规模减半
def binary_search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1

# O(n)：单次遍历
total = sum(nums)

# O(n log n)：分治排序
sorted(nums)  # Timsort

# O(n^2)：嵌套循环
def has_dup(nums):
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] == nums[j]:
                return True
    return False
```

## 数据结构操作速查表

| 操作 | 数组 | 链表 | 哈希表 | 平衡二叉树 |
|------|------|------|--------|------------|
| 按值查找 | O(n) | O(n) | O(1) 平均 | O(log n) |
| 按索引访问 | O(1) | O(n) | — | O(log n) |
| 插入 / 删除 | O(n) | O(1)（已知位置） | O(1) 平均 | O(log n) |

## 易错点

1. 大 O 忽略常数和低阶项，但工程上常数也重要（哈希表常数远大于数组）。
2. 哈希表最坏退化为 O(n)（冲突严重时变链表扫描）。
3. 递归复杂度 = 递归调用次数 × 每次调用的工作量；小心隐藏成本，如 Python 切片 `a[i:]` 是 O(k)。
4. 空间复杂度别忘算递归栈深度：快排平均 O(log n) 栈空间。
5. 字符串拼接在循环里反复 `s += x` 可能退化为 O(n²)，改用 `"".join()`。

## 我的理解

口诀：一层循环 O(n)；循环内折半 O(log n)；循环套循环 O(n²)；"分成两半再合并" O(n log n)。做题时先看数据结构和循环结构，再估数量级，比逐行数更快。
