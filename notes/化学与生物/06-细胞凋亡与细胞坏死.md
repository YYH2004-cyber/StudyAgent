# 细胞凋亡与细胞坏死

> 分类：生物 | 日期：2026-10-12 | 标签：细胞生物学

## 关键点

细胞死亡有两套完全不同的剧本：

| | 细胞凋亡 | 细胞坏死 |
| --- | --- | --- |
| 性质 | 程序性死亡（基因调控，"计划内"） | 被动损伤死亡（"事故"） |
| 诱因 | 内部遗传程序 / 温和外界信号 | 极端理化损伤（缺血流、高温、强酸、毒素） |
| 细胞膜 | 完整，内陷出芽形成凋亡小体 | 破裂，内容物外泄 |
| 细胞形态 | 皱缩，染色质凝聚、DNA 片段化梯状电泳 | 肿胀、溶解 |
| 炎症反应 | 基本不引发 | 引发炎症 |

生物学意义：凋亡是"主动的清场"——胚胎发育中手指间蹼的消除、蝌蚪尾巴的吸收、免疫系统清除自身反应性 T 细胞、清除受损或癌变倾向的细胞，都靠它。凋亡失控（该死不死）与肿瘤、自身免疫病相关；凋亡过度则与神经退行性疾病（如阿尔茨海默病）有关。

## 易混淆

凋亡由基因决定≠只有内部因素，外部信号（如某些激素、免疫细胞的诱导）也能启动程序；坏死则纯属外界伤害。
