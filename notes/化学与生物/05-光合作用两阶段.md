# 光合作用两阶段

> 分类：生物 | 日期：2026-10-12 | 标签：植物, 代谢

光合作用总反应式：**6CO₂ + 12H₂O --光能/叶绿体--> C₆H₁₂O₆ + 6O₂ + 6H₂O**。但这是一个"总账"，实际分成两个阶段，场所、原料、产物各不相同，先分清再谈联系。

## 两阶段对比表

| 项目 | 光反应 | 暗反应（卡尔文循环） |
| --- | --- | --- |
| 场所 | 类囊体薄膜（基粒上） | 叶绿体基质 |
| 条件 | 必须有光、色素、酶 | 有无光均可、多种酶 |
| 原料 | 水、ADP、Pi、NADP⁺ | CO₂、ATP、NADPH |
| 产物 | O₂、ATP、NADPH | (CH₂O)（糖类）、ADP、Pi、NADP⁺ |
| 能量变化 | 光能 → ATP、NADPH 中活跃的化学能 | 活跃化学能 → 有机物中稳定的化学能 |
| 物质变化实质 | 水的光解 + ATP 合成 | CO₂ 的固定 + C₃ 的还原 |

## 各阶段拆解

### 光反应（类囊体薄膜）

1. **色素吸收光能**：叶绿素 a/b 主要吸收红光和蓝紫光，类胡萝卜素吸收蓝紫光并保护叶绿素。光能传递给叶绿素 a 的特殊分子对，引起水的光解。
2. **水的光解**：2H₂O → 4H⁺ + 4e⁻ + O₂。氧气全部来自水——用 ¹⁸O 标记实验证实过。
3. **ATP 与 NADPH 生成**：电子经传递链（配合光合磷酸化）把能量存进 ATP，NADP⁺ 得电子和 H⁺ 变成 NADPH。

### 暗反应 / 卡尔文循环（基质）

1. **CO₂ 的固定**：1 分子 CO₂ 与 1 分子 C₅（RuBP）结合，生成 2 分子 C₃（3-磷酸甘油酸）。这是 Rubisco 酶催化的步骤，也是限速步骤。
2. **C₃ 的还原**：C₃ 接受 ATP 的能量和 NADPH 的氢，被还原成糖类（C₃ 糖磷酸三碳糖，再进一步合成葡萄糖、淀粉、蔗糖）。
3. **C₅ 再生**：部分 C₃ 重新组合成 C₅，循环得以继续。每固定 3 个 CO₂ 净得 1 个三碳糖，消耗 9 ATP、6 NADPH。

## 两阶段的联系（必考）

- 光反应为暗反应提供 **ATP（能量）和 NADPH（还原力）**；暗反应为光反应补充 **ADP、Pi、NADP⁺**。
- 环环相扣的例证：突然遮光 → ATP、NADPH 下降 → C₃ 还原受阻 → C₃ 积累、C₅ 减少；突然停 CO₂ → 固定停止 → C₅ 积累、C₃ 减少。这类"突然改变条件看 C₃/C₅ 变化"的题目用上表即可秒推。

## 易混淆

- **场所辨析**：光反应在"类囊体薄膜"，暗反应在"基质"，笼统说"叶绿体"在填空题会丢分。
- **暗反应不是不需要光**：只是不直接用光子，它依赖光反应产物，所以整体上白天夜里不成对发生。
- **C₃ 植物 vs C₄ 植物**：玉米、甘蔗等先由 PEP 羧化酶把 CO₂ 固定成 C₄，再送进维管束鞘细胞的卡尔文循环，高温强光下更高效——属于拓展内容。

## 延伸阅读

- 卡尔文用 ¹⁴C 标记 CO₂ 追踪碳路径（"闪秒实验"），1961 年获诺贝尔化学奖，循环因此得名。
