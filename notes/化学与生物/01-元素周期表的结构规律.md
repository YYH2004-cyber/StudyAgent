# 元素周期表的结构规律

> 分类：化学 | 日期：2026-10-12 | 标签：无机化学, 原子结构

元素周期表不是一张简单的元素清单，而是按"电子排布"组织起来的地图。抓住"周期 = 电子层数、族 = 价电子数"这条主线，大部分规律都能推出来。

## 关键点

### 1. 周期与族

- **周期（横行）**：共 7 个周期。周期数 = 电子层数。第 1 周期 2 种元素，第 2、3 周期各 8 种（短周期），第 4、5 周期各 18 种，第 6 周期 32 种（含镧系），第 7 周期 32 种（含锕系，2016 年排满）。
- **族（纵列）**：18 个纵列，分为 7 个主族（A 族）、7 个副族（B 族）、第 Ⅷ 族（3 列）和 0 族（稀有气体）。主族族序数 = 最外层电子数（多数情况）。
- **区**：s 区、p 区、d 区、ds 区、f 区，按价电子填充的轨道划分。

### 2. 电子排布规律

- **构造原理（能量最低）**：电子按能级从低到高填充，顺序为 1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p → 5s → 4d → 5p →……注意 4s 能级低于 3d，所以先填 4s（如 K、Ca），再回填 3d（过渡金属）。
- **泡利不相容原理**：每个轨道最多容纳 2 个自旋相反的电子。
- **洪特规则**：电子在等价轨道（如 3 个 2p）上优先分占、且自旋平行，使体系能量最低。
- **全满 / 半满更稳定**：如 Cr 是 3d⁵4s¹ 而非 3d⁴4s²，Cu 是 3d¹⁰4s¹。

### 3. 同周期、同主族的递变规律

| 性质 | 同周期（左→右） | 同主族（上→下） |
| --- | --- | --- |
| 原子半径 | 减小 | 增大 |
| 最高正价 | +1 → +7（O、F 除外） | 等于族序数（不变） |
| 金属性 | 减弱 | 增强 |
| 非金属性 | 增强 | 减弱 |
| 第一电离能 | 总趋势增大（Be>N、Mg>Al 等反常） | 减小 |
| 电负性 | 增大 | 减小 |
| 最高价氧化物水化物酸碱性 | 碱性减弱、酸性增强 | 碱性增强、酸性减弱 |

推理链条要记住：**核电荷数增大 → 原子半径减小 → 原子核对最外层电子引力增强 → 得电子能力增强、失电子能力减弱**。

## 易混淆

- **元素性质 vs 粒子半径比较**：比较离子半径要先看电子层数，再看核电荷数（层数相同，核电荷越大半径越小，如 Na⁺ > Mg²⁺ > Al³⁺）。
- **0 族 vs Ⅷ 族**：稀有气体是 0 族（右端），第 Ⅷ 族是铁钴镍所在的中间 3 列，别混。
- **"位—构—性"三者互相推断**：位置、结构、性质可以两两互推，这是考试常用思路。

## 延伸阅读

- 门捷列夫 1869 年按原子量排序并留空位预言"类铝"（镓）、"类硅"（锗），是周期表最有名的故事。
- 现代 IUPAC 命名 113 号（鉨 Nh）、115 号（镆 Mc）等超重元素，均已按新规则用国名/人名命名。
