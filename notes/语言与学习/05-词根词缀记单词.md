# 词根词缀记单词

> 分类：英语学习 | 日期：2026-10-12 | 标签：词汇, 构词法, 表格

原理：英语词汇的绝大多数（尤其学术词汇）来自拉丁、希腊语素。掌握高频词根词缀 ≈ 拿到一批"偏旁部首"，生词可以猜、熟词可以串记。适合中高级词汇扩张，不适合零基础高频口语词（那些直接整词记更快）。

## 一、常见前缀

| 前缀 | 含义 | 例词 |
|---|---|---|
| re- | 再次；回 | return 返回；rebuild 重建 |
| pre- | 前 | preview 预览；predict 预言（pre + dict 说） |
| post- | 后 | postpone 推迟；postwar 战后 |
| un- / in- / im- / il- / ir- | 不（in- 随首字母同化） | unfair；incorrect；impossible；illegal；irregular |
| dis- | 不；分离 | disagree；disconnect |
| mis- | 错 | misunderstand 误解；mislead 误导 |
| sub- | 下；次 | subway 地铁；submarine 潜艇（sub + mar 海） |
| super- | 上；超 | supervise 监督（super + vis 看）；supernatural |
| inter- | 之间；互相 | international；interview（inter + view 看） |
| trans- | 跨；转移 | transport 运输；transfer 转移 |
| ex- | 向外；前任 | export 出口；ex-president |
| com- / con- / col- / cor- | 共同；一起 | connect；cooperate；collaborate；correspond |
| de- | 去除；向下；反向 | decode 解码；decrease 下降 |
| over- / under- | 过度 / 不足 | overestimate 高估；underestimate 低估 |
| anti- | 反对 | antibody 抗体（anti + body） |
| auto- | 自身 | automatic；autobiography 自传 |
| bi- / tri- / multi- / poly- | 二 / 三 / 多 | bicycle；triangle；multimedia；polygon 多边形 |
| tele- | 远 | telephone；telescope 望远镜（tele + scope 看） |

## 三、高频词根

| 词根 | 含义 | 例词 |
|---|---|---|
| spect / spic | 看 | inspect 检查；respect 尊重（反复看）；suspect 怀疑（从下看） |
| vis / vid | 看 | visible；vision；evident 明显的（看出来的） |
| dict | 说 | dictionary 词典；predict 预言；contradict 反驳（ contra 反 + dict） |
| duc / duct | 引导 | educate（e 向外 + duc 引出）；conduct；reduce |
| mit / miss | 送、放 | submit 提交；permit 允许；mission 使命 |
| port | 携带 | import 进口；transport；portable 便携的 |
| ject | 扔 | reject 扔回→拒绝；project 投射/项目；inject 注射 |
| struct | 建造 | construct 建造；instruct 指导；structure |
| fer | 带来 | transfer 转移；prefer 更喜欢；offer 提供 |
| cred | 相信 | credit 信用；incredible 难以置信 |
| form | 形状 | reform 改革；transform 改变；uniform 制服（同一形状） |
| scrib / script | 写 | describe 描写；manuscript 手稿（manu 手 + script） |
| graph | 写、画 | photograph 摄影术；biography 传记（bio 生命 + graph） |
| log / logue | 言说；学科 | dialogue 对话；biology 生物学；logic 逻辑 |
| path | 感受 | sympathy 同情（sym 共同 + path）；empathy 共情 |
| phon | 声音 | telephone；symphony 交响乐（共同发声） |
| aud | 听 | audience 听众；audible 听得见的 |
| vid 变体 / cap / cept / ceive | 拿、取 | capture 捕获；accept 接受；receive 收到 |
| vert / vers | 转 | convert 转变；reverse 反转；universe 宇宙（转成一体） |
| tract | 拉 | attract 吸引；contract 收缩；extract 提取 |
| rupt | 破裂 | interrupt 打断；bankrupt 破产（bank + rupt） |
| chron | 时间 | chronic 慢性的；synchronize 同步（syn 共同 + chron 时间） |
| bio / geo | 生命 / 地球 | biology；geography；geology 地质学 |

## 实践记录

- 一个实用的记法：同一个词根下挑 2-3 个已认识的熟词当"锚"，新词挂在锚上。比如已知 respect，再记 inspect / suspect / retrospect（回顾）。
- 配合 Anki：正面写词根（spect = 看），背面列 3 个例词 + 一句话串记，比单独背裸词根有效。

## 待验证

- 猜词有边界：词根义 ≠ 词义（如 nice 源自"无知"），构词法只当线索、不当词典，遇到关键场合还是要查证。
