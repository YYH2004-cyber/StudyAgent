# 批判性思维要点

> 分类：思维方法 | 日期：2026-10-12 | 标签：思维, 逻辑, 谬误

批判性思维不是"会抬杠"，而是**评估论证**的能力：判断一个结论有多值得相信。拆解一切从论证结构开始。

## 一、论证结构

最简模型：**前提 + 推理 → 结论**。评估两问：

1. **前提可信吗？**（事实问题：数据、来源、样本）
2. **前提能推出结论吗？**（逻辑问题：推理是否有效）

要素清单：

- **结论**：对方到底想让你接受什么？经常藏在段尾或标题，先找它。
- **理由/前提**：支持结论的陈述，包括数据和例子。
- **隐含前提（assumption）**：没说出口但必需的桥。例如"老王吸烟，所以不健康"隐含"吸烟导致不健康"。大量谬误藏在隐含前提里。
- **限定词**：好的论证有"多数情况下""在 X 范围内"；全天候的断言要警惕。

注意区分：**论证**（给理由）vs **解释**（给原因）vs **说服**（只给情绪）。只有第一种可以按逻辑评估。

## 二、常见谬误

| 谬误 | 手法 | 例子 |
|---|---|---|
| 稻草人 | 歪曲对方观点再攻击 | 对方说"减少糖摄入"，你反驳"他要禁售所有甜食" |
| 滑坡 | 无依据地串起连锁灾难 | "今天允许迟到，明天就没人上班，公司就完了" |
| 虚假两难 | 把连续谱系砍成二选一 | "不支持这个方案就是不爱国" |
| 诉诸人身 | 攻击说话者而非论点 | "他离过婚，他的教育观点不可信" |
| 诉诸权威 | 权威跨领域担保 | "诺奖得主也这么保健" |
| 诉诸大众 | 人多=正确 | "几亿人都在买，还能有假？" |
| 循环论证 | 结论当前提 | "这药有效，因为吃了病好了；病好了就是药有效的证明" |
| 相关当因果 | 先后/共变≠因果 | "冰淇淋销量与溺水同步上升"（共同原因：夏天） |
| 举证责任转移 | 让对方证伪 | "你说我不对，你证明给我看" |
| 事后归因 | 事后即因 | "换了枕头后业绩变好，枕头立功了" |

## 三、提问清单（读文章/听演讲时过一遍）

1. 结论是什么？作者最想让我接受哪一句？
2. 支撑它的理由有哪些？哪些是事实，哪些是观点/传闻？
3. 数据来源？样本多大、怎么抽的？有没有对照组？
4. 隐含前提是什么？它成立吗？
5. 有没有反例、例外、被略去不提的相反证据？
6. 关键词有歧义吗？（"有效""天然""大幅"）
7. 有没有替代解释？（尤其相关-因果场景）
8. 对我有利益相关吗？谁从这个结论中获益？

## 实践记录

- 实操中最先问第 1 条：**先找到结论再读理由**，阅读效率高很多，而且能立刻暴露"堆了一堆事实但根本没论证"的文章。
- 谬误表格背了没用，靠标注练习：找一篇评论文章，逐段标出前提/结论/隐含前提，坚持几篇后识别谬误变成自动反应。
- 对自己也要用：写完一段论证后跑一遍清单，最常见的自我翻车是"隐含前提没检验"和"拿个例当普遍"。

## 待验证

- 图尔敏模型（主张-数据-担保-支撑-限定-反驳）比三段论更适合日常论辩分析，只了解皮毛，待系统学一遍。
